# Onderhoud & storingen

Doel: zelfstandig storingen kunnen oplossen, ook ver van een dealer.

## Onderhoudsintervallen
*Nog te vullen: voertuig (MAN-schema), verwarming (Autoterm), accu (balans/celspanningen), koelvloeistof, filters.*

## Meetpunten na inbouw
- [ ] Spanningsval startaccu − ↔ Lynx − bij 80A laden < 0,1V
- [ ] Per Fusy-groep: continue stroom en startpiek meten (rev C zekeringen)
- [ ] Celspanningen en balans na eerste volle lading

## Storingen zoeken
*Per systeem een beslisboom: geen 24V, Orions laden niet, kachel start niet, …*

## Gereedschap & diagnose aan boord
- OBDLink MX (Bluetooth OBD)
