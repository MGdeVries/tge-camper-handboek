# Waar zit wat

De bus is opgedeeld in **zones**. Elk onderdeel in de database verwijst naar een zone, zodat je onderweg snel weet waar je moet zoeken.

!!! note "Voorstel – nog te bevestigen"
    De zone-indeling hieronder is een eerste voorstel op basis van de indeling (2 dwarsbedden achter, kinderbedden eronder, garderobe en badkamer aan bestuurderszijde, keuken en koelkast aan passagierszijde).

| Zone | Omschrijving |
|---|---|
| Z01 | Cabine – dashboard, onder stoelen, B-stijl |
| Z02 | Zitruimte / bank (Schnierle-stoelen) |
| Z03 | Keuken, passagierszijde |
| Z04 | Koelkast (staand) |
| Z05 | Garderobe, bestuurderszijde |
| Z06 | Badkamer |
| Z07 bestuurderszijde | Garage / techniekruimte achter, bestuurderszijde: (bijna) alle elektra |
| Z07 passagierszijde | Garage / techniekruimte achter, passagierszijde: waterpomp, filters, Baltica-vloeistoftank |
| Z08 | Bedden achter (dwars) + kinderbedden |
| Z09 | Plafond / dak (MaxxFans, zonnepanelen, dakrek) |
| Z10 | Onder de bus (tanks, leidingen, dieseltank) |
| Z11 | Motorruimte |
| Z12 | Vloer – geïsoleerde vloeropbouw met vloerverwarming, kabelgoten en bevestigingspunten (zie [Vloer](../interieur/vloer.md)) |
